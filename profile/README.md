# MeshLab - Mesh View, Filter List, and Layer Dialog

## About MeshLab

MeshLab is a mesh client for a scan or solid you own. MeshLab Mesh View is the viewport. MeshLab Filter List is filters you can still name. MeshLab Layer Dialog is extra meshes in the same file. MeshLab Color Map is a check, not a paint job. MeshLab Align Tool is registration of scans you collected.

Open a mesh you own. Look at it in MeshLab Mesh View. Duplicate a layer in MeshLab Layer Dialog before a risky filter. Run one item from MeshLab Filter List you can name. Use MeshLab Color Map to see quality. Use MeshLab Align Tool only on scans you collected or were given. Save before a decimate.

MeshLab Mesh View, MeshLab Filter List, MeshLab Layer Dialog, MeshLab Color Map, and MeshLab Align Tool exist to clean a mesh you already have a reason to clean.

## Key Features of MeshLab

- **Mesh view as the viewport** – MeshLab Mesh View is what you see. MeshLab Layer Dialog picks which mesh. MeshLab Filter List changes it. MeshLab Color Map paints a check. MeshLab Align Tool moves a layer.
- **Filter list as a named pass** – MeshLab Filter List is a filter you can name. Run it on a copy. MeshLab Layer Dialog holds that copy. MeshLab Mesh View shows it. MeshLab Color Map can prove it. MeshLab Align Tool should run before a merge, not after a mystery filter.
- **Layer dialog as extra meshes** – MeshLab Layer Dialog is the original plus copies. Keep the original. MeshLab Mesh View can hide a layer. MeshLab Filter List should target a named layer. MeshLab Color Map per layer. MeshLab Align Tool picks two layers you collected.
- **Color map as a check** – MeshLab Color Map is quality or scalar. Not a paint job. MeshLab Mesh View then shows problems. MeshLab Filter List can follow. MeshLab Layer Dialog still has the original. MeshLab Align Tool error can show as color if you named that.
- **Align tool as scans you collected** – MeshLab Align Tool is registration. Only scans you collected or were given. MeshLab Layer Dialog holds both. MeshLab Mesh View checks overlap. MeshLab Filter List merge comes after. MeshLab Color Map can show residual.

## Quick Start with MeshLab

1. **One mesh** – Open in MeshLab Mesh View. Duplicate in MeshLab Layer Dialog. Ignore MeshLab Filter List. Ignore MeshLab Color Map. Ignore MeshLab Align Tool.
2. **One named filter** – Run one item from MeshLab Filter List on the copy. Check MeshLab Mesh View. Original still in MeshLab Layer Dialog. Optional MeshLab Color Map. No MeshLab Align Tool yet.
3. **Color as a check** – Apply MeshLab Color Map. Confirm MeshLab Mesh View. MeshLab Filter List unchanged. MeshLab Layer Dialog still has original. No MeshLab Align Tool.
4. **Align only your scans** – Two layers in MeshLab Layer Dialog you collected. MeshLab Align Tool. Check MeshLab Mesh View. Optional MeshLab Color Map of residual. MeshLab Filter List merge only after overlap is true.
5. **Review** – Original layer kept. MeshLab Filter List you can name. MeshLab Layer Dialog honest. MeshLab Color Map a check. MeshLab Align Tool only your scans. MeshLab Mesh View exportable. File dated.
